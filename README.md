# 📦 StockFlow

Controle de estoque para indústrias e empresas: organize materiais, acompanhe saldos e identifique necessidades de reposição.

**Sua indústria em movimento, seu estoque sob controle.**

## 🌐 Acesso

[stockflowbr.netlify.app](https://stockflowbr.netlify.app)

## ⚙️ Funcionalidades

- Cadastro, pesquisa e edição de materiais com 12 categorias.
- Quantidade inicial com entrada automática e estoque mínimo para reposição.
- Entradas, saídas e histórico com data, hora e observação opcional.
- Consulta de saldos, bloqueio de saídas superiores ao disponível e indicadores de estoque.
- Duas páginas responsivas e carrossel com imagens de ambientes industriais.

## 🛠️ Tecnologias

HTML, CSS, JavaScript, Bootstrap e localStorage.

Bootstrap distribuído sob a [licença MIT](https://github.com/twbs/bootstrap/blob/v5.3.8/LICENSE).

## ▶️ Como executar

Abra a pasta no VS Code e inicie `index.html` com a extensão Live Server. O Bootstrap depende de conexão com a internet.

Os dados ficam salvos no navegador utilizado e não são compartilhados entre computadores. Esta versão não possui controle de acesso. Utilize uma aba por vez para registrar alterações.
