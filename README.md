# StockFlow

**Sua indústria em movimento, seu estoque sob controle.**

Sistema de controle de estoque industrial voltado a pequenas indústrias.

O objetivo é organizar materiais, acompanhar entradas e saídas e identificar
necessidades de reposição.

## 🛠️ Tecnologias previstas

HTML5, CSS3, JavaScript puro, Bootstrap 5 e localStorage.

## 🚀 Desenvolvimento

A estrutura inicial está em preparação. As funcionalidades serão documentadas
conforme forem implementadas.
